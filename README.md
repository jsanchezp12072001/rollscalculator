# Simulador de consumo de material

Conversión del archivo React `simulador_extrusion(1).jsx` a una aplicación web estática.

## Archivos
- `index.html`
- `styles.css`
- `script.js`

## Características
- Inventario editable por material.
- Restablecer inventario original.
- Cálculo automático de consumo y material limitante.
- Tiempo máximo de operación.
- Estimación de rollos.
- Cálculo de gaylords restantes.
- Meta de rollos y cálculo de material requerido.
- Alertas de faltantes.
- Diseño responsive.

## GitHub Pages
Sube los tres archivos a la raíz del repositorio. Luego entra en:

`Settings → Pages → Deploy from a branch → main → / (root) → Save`

No requiere React, Node.js, npm ni backend. `index.html` es la página que GitHub Pages abrirá automáticamente.
